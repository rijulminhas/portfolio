## Project Objective

Build a highly polished, modern, creative and premium personal portfolio website for:

**Rijul Minhas**
**Full-Stack Developer**

The website must NOT look like a generic developer portfolio, template, Bootstrap website, or simple resume page.

It should feel like a premium digital product / interactive developer experience that immediately communicates:

- Strong full-stack development skills
- Real-world production experience
- Modern Next.js/React expertise
- Backend and database knowledge
- Real-time application experience
- UI/UX attention to detail
- Performance optimization

# 19. ANIMATION SYSTEM

Animations are extremely important.

Use Motion / Framer Motion.

Implement:

- Page entrance animation
- Section reveal
- Staggered cards
- Smooth hover transitions
- Magnetic buttons where appropriate
- Cursor-reactive background
- Parallax
- Project card movement
- Text reveal
- Number animations
- Timeline animations
- Navigation transitions
- Modal transitions

However:

DO NOT animate everything.

Use animation to establish hierarchy.

Animations should generally be:

- 200–700ms
- smooth
- spring-based where appropriate
- subtle

Use easing such as:

easeOut
easeInOut

Respect:

prefers-reduced-motion

When reduced motion is enabled, disable unnecessary movement.

---

# 20. 3D BACKGROUND IMPLEMENTATION

Prefer lightweight CSS/DOM-based 3D effects first.

Do NOT automatically introduce Three.js unless the visual absolutely requires it.

The site must remain fast.

Possible implementation:

- CSS perspective
- transform-style: preserve-3d
- translate3d
- floating cards
- animated grid
- radial gradients
- blur layers
- mouse position variables

Example conceptual structure:

<div className="perspective">
  <div className="floating-layer">
    ...
  </div>
</div>

Use requestAnimationFrame only when needed.

Avoid expensive continuous React state updates for cursor movement.

Prefer CSS variables for high-frequency pointer interactions.
